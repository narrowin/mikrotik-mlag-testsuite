## Cases

### Pair A secondary reboot · two MLAG pairs, field priorities, pair A 0x2000, pair B 0x4000 · RSTP

Resets the data bridge on all four CHRs over management SSH with protocol-mode=rstp and bridge priority 0x2000 on pair A and 0x4000 on pair B, the field design with one priority per pair. Pair A (CHR 1 MLAG primary, CHR 2 MLAG secondary) and pair B (CHR 3 MLAG primary, CHR 4 MLAG secondary) are joined by one distributed LACP bond, mlag-id 11 on pair A and 21 on pair B. Host 1 bonds to pair B and host 2 to pair A, so both VLAN 110 streams cross both pairs. It requires a loss-free baseline with root 0x2000.02:00:00:21:00:11 on all four CHRs. It then reboots CHR 2 (pair A's MLAG secondary) with `/system reboot`, waits for the guest uptime to reset and keeps probing for 16 s plus a 3 s recovery window. Run it with `mlag-lab run --case two-pair-field-reboot-a-secondary`.

- **Pair A secondary down:** CHR 1 keeps pair A's bridge ID, so the root does not change.
