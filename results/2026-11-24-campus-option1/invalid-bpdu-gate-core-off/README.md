### Baseline · STP off on the MLAG pair, RSTP on the access switch (campus option 1) · STP off

Resets the data bridge on all three CHRs over management SSH: protocol-mode=none and forward-reserved-addresses=no on both MLAG peers, protocol-mode=rstp priority=0x0000 on the access switch, with edge=yes on its uplink bond and edge=yes, bpdu-guard=yes and loop-protect=on on its host port ether4, and reads the access switch port settings back. Then run numbered 100 ms pings for 4 s in both VLAN 110 and both bypass directions, read back bridge, MLAG, RSTP and LACP state, and send three ARP broadcasts each way. No fault is applied. Run it with `mlag-lab run --case medium-core-off-baseline`.

- **Baseline:** Both MLAG peers run protocol-mode=none with forward-reserved-addresses=no, so they neither send BPDUs nor pass the access switch's BPDUs (STP group address 01:80:C2:00:00:00). The access switch is the only RSTP bridge and, with priority 0x0000, its own root (root ID 0x0000.02:00:00:21:00:13). Its uplink bond is an edge port, so it forwards at once without a proposal/agreement handshake, and its host port ether4 is an edge port with bpdu-guard=yes and loop-protect=on. MLAG is connected, every bond member is synchronized, collecting and distributing, each ARP broadcast arrives once and all four streams deliver with zero loss.
