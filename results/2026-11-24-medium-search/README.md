### MLAG primary reboot · Medium lab, MSTP, access switch as root · MSTP

Resets all three bridges over management SSH with protocol-mode=mstp, priority 0x1000 on CHR 1 and CHR 2 and 0x0000 on the access switch. It requires a loss-free baseline with the access switch as root (0x0000.02:00:00:21:00:13). It then reboots CHR 1 (MLAG primary) with `/system reboot`, waits for the guest uptime to reset and keeps probing for 16 s plus a 3 s recovery window. Run it with `mlag-lab run --case medium-mstp-access-root-reboot-primary`.
