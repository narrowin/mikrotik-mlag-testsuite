## Cases

### Baseline · MSTP, MLAG pair as root · MSTP

Reset the data bridge on all three CHRs over management SSH with protocol-mode=mstp, priority 0x1000 on both MLAG peers and 0x8000 on the access switch. Then run numbered 100 ms pings for 4 s in both VLAN 110 and both bypass directions and read back bridge, MLAG, RSTP and LACP state. No fault is applied. Run it with `mlag-lab run --case medium-mstp-pair-root-baseline`.

| Phase | Expected | Limit | Run 1 |
| --- | --- | --- | --- |
| Baseline | Both MLAG peers are connected and use the MLAG primary's system ID as the shared RSTP bridge ID, so both show as root bridge with root ID 0x1000.02:00:00:21:00:11. | no loss | ⚠️ INVALID · no loss · [failed check](01-medium-mstp-pair-root-baseline/result.json#L266) |

- **Baseline:** Both MLAG peers are connected and use the MLAG primary's system ID as the shared RSTP bridge ID, so both show as root bridge with root ID 0x1000.02:00:00:21:00:11. The access switch picks its non-edge uplink bond as root port and all VLAN 110 ports forward. RSTP BPDUs from that root reach the access switch, and all four streams deliver with zero loss. [Source](https://manual.mikrotik.com/docs/high-availability-solutions/multi-chassis-link-aggregation-group/)
- **MikroTik fixes this case checks:** Packets looped back to a dual-connected bond ([7.25.2](https://cdn.mikrotik.com/routeros/7.25.2/CHANGELOG)); BPDUs leaking to the wrong dual-connected bond (introduced in 7.24) ([7.24.6](https://cdn.mikrotik.com/routeros/7.24.6/CHANGELOG)); LACP system ID not synchronised when bonds are created before MLAG ([7.25.2](https://cdn.mikrotik.com/routeros/7.25.2/CHANGELOG)); MLAG peer stuck in the disabled state after config changes ([7.25](https://cdn.mikrotik.com/routeros/7.25/CHANGELOG)); MLAG state permanently disabled after changing bridge settings ([7.22](https://cdn.mikrotik.com/routeros/7.22/CHANGELOG)); MLAG with MSTP: support and stability ([7.14](https://cdn.mikrotik.com/routeros/7.14/CHANGELOG)); Priority setting to elect the MLAG primary ([7.17](https://cdn.mikrotik.com/routeros/7.17/CHANGELOG))
