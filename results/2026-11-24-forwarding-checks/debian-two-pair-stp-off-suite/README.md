## Cases

### Baseline · two MLAG pairs, spanning tree off · STP off

Resets the data bridge on all four CHRs over management SSH with protocol-mode=none. Pair A (CHR 1 MLAG primary, CHR 2 MLAG secondary) and pair B (CHR 3 MLAG primary, CHR 4 MLAG secondary) are joined by one distributed LACP bond, mlag-id 11 on pair A and 21 on pair B. Host 1 bonds to pair B and host 2 to pair A, so both VLAN 110 streams cross both pairs. Then runs numbered 100 ms pings for 4 s in both VLAN 110 and both bypass directions and reads back bridge, MLAG and LACP state on all four CHRs. No fault is applied. Run it with `mlag-lab run --case two-pair-stp-off-baseline`.

| Phase | Expected | Limit | Run 1 | Run 2 |
| --- | --- | --- | --- | --- |
| Baseline | Both pairs are connected, with CHR 1 and CHR 3 as MLAG primaries. | no loss | ✅ PASS · no loss | ✅ PASS · no loss |

- **Baseline:** Both pairs are connected, with CHR 1 and CHR 3 as MLAG primaries. With protocol-mode=none no bridge sends or forwards BPDUs. Every member of the inter-pair bond and both host bonds is synchronized, collecting and distributing, and all four streams deliver with zero loss. [Source](https://manual.mikrotik.com/docs/high-availability-solutions/multi-chassis-link-aggregation-group/)

### Inter-pair bond member flap · two MLAG pairs, spanning tree off · STP off

Resets the data bridge on all four CHRs over management SSH with protocol-mode=none. Pair A (CHR 1 MLAG primary, CHR 2 MLAG secondary) and pair B (CHR 3 MLAG primary, CHR 4 MLAG secondary) are joined by one distributed LACP bond, mlag-id 11 on pair A and 21 on pair B. Host 1 bonds to pair B and host 2 to pair A, so both VLAN 110 streams cross both pairs. It requires a loss-free baseline. It then takes the inter-pair bond member between CHR 1 ether3 and CHR 3 ether3 down at both ends (both container veths and both QEMU NICs), holds it down for 8 s, brings both ends back up and watches 8 s of return plus a 3 s recovery window. The bridge host table size and the topology-change counter of every CHR are sampled throughout. Run it with `mlag-lab run --case two-pair-stp-off-interpair-member-flap`.
